# Veilbreaker

A planar action RPG in the browser. You are a wanderer in **Ashenford**, where the First Gate that bound the planes has cracked. Shards of the Circlet of Binding fell into five worlds. Recover them, or watch the Material Plane drown in Fey light, gray sorrow, infernal contracts, and the Abyss.

This first chronicle is a playable vertical slice of a larger game: Dungeons & Dragons races and classes (SRD 5.1), action combat, a Diablo-like skill lattice, Skyrim/RuneScape use-based skills, branching NPC dialogue, generated side work, and a loot table with prefixes, suffixes, and rarity.

## Play

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

```bash
npm test
npm run build
```

## How it plays

- **WASD** move · **Shift** sprint · **Space** dodge · **Mouse** aim · **Click** strike
- **1–4** class abilities (unlock more on the lattice)
- **E** speak, pass a portal, rest at a shrine, open a chest
- **I** inventory · **K** skill lattice · **J** journal · **C** character · **M** map · **Esc** pause

Start in the Cracked Stein. Talk to **Mira Venn**. The Gate stands east. Planar doors:

| Plane | Where in Ashenford |
| --- | --- |
| Feywild | Standing stones, north wood |
| Shadowfell | Graveyard well, south |
| Nine Hells | Infernal circle, southwest (Vex will tell you) |
| Abyss | Chapel crater-well |

Bosses drop **Circlet shards**. Five shards at the First Gate reseal the wound — after a fight.

## What is in this slice

- Nine SRD races and twelve classes, each with a skill lattice
- Use-based skills (melee, archery, magic schools, speech, crafting…)
- Affix loot from common through artifact
- Authored NPCs with checks for race, class, and Speech
- Random townsfolk who can hand out extra jobs
- Five distinct planes with shrines, chests, and a boss

Races, classes, and cosmology follow the D&D 5.1 Systems Reference Document. The kingdom of Vaelthorn and the town of Ashenford are original.
